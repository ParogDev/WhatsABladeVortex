Drop your "snapshot_lost.wav" here.

The plugin plays Sounds/<SoundFile setting value> (default snapshot_lost.wav)
via System.Media.SoundPlayer when every Blade Vortex blade expires and the
Minion Pact snapshot is lost. The file MUST be a .wav (PCM) - SoundPlayer does
not support .mp3 / .ogg.

Suggested source clip (user-provided):
https://www.youtube.com/watch?v=9t9pDnG0SeM

If the file is missing the plugin silently skips the sound; the red header
and edge flash alerts still work.
